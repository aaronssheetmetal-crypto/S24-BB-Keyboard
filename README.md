# S24 BB Keyboard

Offline BlackBerry-style Android system keyboard designed for Samsung Galaxy S24.

## Features
- System-wide Android IME
- High-contrast BB-inspired keys
- Flying-word animation when Space is pressed
- Haptic key feedback
- No Internet permission and no typed-text collection
- English (Australia), portrait and landscape compatible

## Install
Download the `S24-BB-Keyboard-APK` artifact from the latest successful GitHub Actions run, extract `app-debug.apk`, and install it. Then open the app, tap **Enable keyboard**, enable **S24 BB Keyboard**, and tap **Select keyboard**.

Android displays a standard warning when enabling any downloaded keyboard. This keyboard declares no Internet permission; review the public source before enabling it.
